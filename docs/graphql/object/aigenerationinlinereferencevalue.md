Represents an inline reference generated by AI, addressable via `${signature}`.

## Fields without arguments

| Name | Type | Description |
|------|------|-------------|
| `signature` | [`String`](../scalar/string.md) | The key addressed via `${signature}`. |
| `value` | [`AiGenerationNodeValue`](../union/aigenerationnodevalue.md) | The generated value this reference resolves to. |
