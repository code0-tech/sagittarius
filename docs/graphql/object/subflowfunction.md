---
title: SubFlowFunction
---

Identifies the sub-flow function a node executed, mirroring Tucana SubFlowFunction.

## Fields without arguments

| Name | Type | Description |
|------|------|-------------|
| `definitionSource` | [`String`](../scalar/string.md) | Source the sub-flow function definition originates from, if any. |
| `functionIdentifier` | [`String`](../scalar/string.md) | Identifier of the sub-flow function. |
